# SnapStudio Booth

Build SNAPSTUDIO, a visually stunning, fully functional virtual photobooth web app.

Design: Premium, gender-neutral, modern UI with a neutral base, vibrant accents, rounded cards, smooth animations, beautiful typography, and a responsive layout. Avoid making the entire app pink or overly feminine.

Photo Modes: Create 8 selectable modes, each with its own frames, filters, stickers, and photo layouts:

Classic Booth

Cinematic

Fun & Meme

Vintage Camera

Music & Concert

Cute & Playful

Editorial

Travel Diary

Core Features:

Live webcam preview with mirror toggle, countdown, multi-shot capture, and retakes.

Upload photos as an alternative to using the camera.

Photo-strip layouts with 2, 4, or 6 shots and collage options.

Sticker library featuring emojis, memes, animals, hearts, flames, stars, music icons, and doodles.

Add, drag, resize, rotate, layer, and delete stickers.

Customize frames, backgrounds, filters, captions, fonts, and date stamps.

Live preview of all edits and downloadable, high-quality PNG exports.

Switch modes anytime and freely mix stickers and customizations across modes.

Technical Requirements: Use React, TypeScript, and Tailwind CSS. Use browser APIs and client-side state only; no backend, authentication, paid APIs, or API keys. Use Canvas or another reliable method to export the complete composition, including photos, filters, frames, captions, and stickers. Handle camera permissions and errors gracefully, and stop camera streams when no longer needed.

Make every button functional, prioritize a polished experience, and ensure the entire workflow works: Capture/Upload → Choose Mode → Customize → Download.

Build the complete application immediately without asking questions. Do not create a static mockup or unnecessary placeholder features.
